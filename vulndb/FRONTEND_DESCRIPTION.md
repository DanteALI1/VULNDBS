# VulnDB — Front-end Описание

## Обзор

**VulnDB** — это полнофункциональное SPA-приложение «Локальная база уязвимостей», выполненное в стилистике Security Operations Center (SOC). Приложение работает полностью на клиенте с моковыми данными, без необходимости бэкенда.

## Технологический стек

### Основные технологии
- **React 18** + **TypeScript** — типизированный UI
- **Vite** — быстрая сборка и hot-reload
- **Recharts** — графики (Area, Bar, Pie, Line)
- **Lucide React** — современные иконки
- **Context API** — управление темой приложения
- **localStorage** — сохранение предпочтений пользователя

### Структура проекта

```
src/
├── context/
│   └── ThemeContext.tsx      # Провайдер темы (dark/light)

│   └── Sidebar.tsx           # Боковая навигация

```

## Ключевые особенности

### 1. Страница авторизации (LoginPage.tsx)

**Дизайн:**
- Фон `#0a0e1a` с CSS-сеткой 50×50px
- Два анимированных glow-эффекта (фиолетовый + красный)
- Левая панель (45% ширины): логотип, терминал, статус-индикаторы
- Правая часть: форма авторизации/регистрации

**Терминал:**
- Построчная анимация текста с задержкой 400мс
- Мигающий курсор █
- Индикаторы: Мониторинг ✓, CVE Feed ✓, Auth ●

**Форма авторизации:**
- Поля: Идентификатор + Пароль с иконками
- Кнопка «Войти в систему» с hover-эффектом
- Спиннер при загрузке
- Ошибка с анимацией shake
- Тестовые данные: **Admin / Admin**

**Анимация переключения:**
- Плавное исчезновение (opacity 0 + translateY -8px) за 350мс
- Расширение формы 420px → 520px
- Движение к центру
- Исчезновение левой панели

### 2. Основное приложение

#### Sidebar (боковая навигация)
- 5 разделов: Дашборд, Уязвимости, Сканер, Отчёты, Настройки
- Кнопка сворачивания (16rem ↔ 5rem)
- Кнопка «Выход»

#### Header (верхняя панель)
- Название текущей страницы + описание
- Переключатель темы (Sun/Moon)
- Поиск по CVE
- Уведомления (dropdown с цветными индикаторами)
- Профиль пользователя

### 3. Страницы приложения

#### Dashboard.tsx
**KPI-карточки (4 шт):**
- Всего уязвимостей
- Критические
- Решено за месяц
- Среднее время устранения

**Графики:**
- AreaChart: Динамика обнаружения vs устранения (6 месяцев)
- PieChart: Распределение по severity
- BarChart: Статусы обработки

**Блок «Требуют внимания»:** Карточки критических уязвимостей с эксплоитами

#### Vulnerabilities.tsx
**Функционал:**
- Таблица с сортировкой по CVSS и дате
- Фильтры: поиск, severity, status, vendor
- Статистика: Всего, Критические, Высокие, Открытые, В работе, С эксплоитом

**Модальное окно деталей:**
- CVE ID, CVSS badge, статус, описание
- Вендор, продукт, дата, ответственный
- Затронутое ПО (моноширинные теги)
- Предупреждение об эксплоите

#### Scanner.tsx
**Три вкладки:**
1. **Сканирования** — таблица истории с результатами
2. **Новое сканирование** — выбор цели, типа скана, параметров
3. **Расписание** — список задач с toggle

**Прогресс сканирования:**
- Прогресс-бар
- 5 этапов с иконками

#### Reports.tsx
**Переключатель периода:** Неделя/Месяц/Квартал/Год

**4 типа отчётов:**
1. Общий обзор (6 метрик)
2. Время устранения (MTTR) — LineChart + SLA
3. По вендорам — StackedBarChart + PieChart
4. Тренды — BarChart + PieChart

**Экспорт:** PDF, CSV, JSON, HTML

#### Settings.tsx
**6 вкладок:**
1. **Профиль** — аватар, имя, email, должность
2. **Уведомления** — toggle по уровням критичности
3. **Безопасность** — 2FA, оповещения, API auth, аудит
4. **База данных** — версия, записи, размер, автообновление
5. **Интеграции** — SMTP, Exchange, LDAP/AD, SSO
6. **API ключи** — список, создание, отзыв

### 4. Система тем (ThemeContext.tsx)

**Хранение:** localStorage (`vulndb-theme`)

**Тёмная тема:**
- Фон: `#0f172a`
- Карточки: `#1e293b`
- Primary: `#6366f1`

**Светлая тема:**
- Фон: `#f8fafc`
- Карточки: `#ffffff`
- Primary: `#4f46e5`

### 5. Цветовая система severity

| Уровень | Цвет | Фон |
|---------|------|-----|
| 🔴 Critical | `#ef4444` | `#fef2f2` |
| 🟠 High | `#f97316` | `#fff7ed` |
| 🟡 Medium | `#eab308` | `#fefce8` |
| 🟢 Low | `#22c55e` | `#f0fdf4` |
| 🔵 Info | `#3b82f6` | `#eff6ff` |

### 6. CSS-анимации

```css
pulse     — glow-эффекты (4s infinite)
blink     — курсор терминала (1s infinite)
shake     — ошибки форм (0.5s)
spin      — спиннеры загрузки (0.8s linear infinite)
float     — фоновые элементы
fadeIn    — появление контента
slideIn   — выдвижение контента
```
